# logdeck

Log analyzer frontend: the shared HTML report deck.

Applications that analyze support bundles each own their 
data processing and section content.
`logdeck` provides a shared GUI and reporting system:

- **the deck** — one self-contained HTML page with a tab bar and viewer JS
  (`render_report(tabs=[{"id","title","content","active"}], now=, title=, heading=, footer=)`),
- **tables** — `dicts_to_html_table(rows, columns, highlight_rules)` with
  escaping, a safe-tag allowlist, and per-column red highlighting,
- **sections** — collapsible `<details>` blocks via `make_section`.

Zero runtime dependencies. Python 3.11+.

## GUI chassis (optional)

`logdeck.gui` provides the shared Tkinter drop-zone window used by the
analyzer apps: browse/drag-drop input, background worker thread with
queue-polled UI updates, indeterminate progress, status colors, report
link, save-next-to-input and auto-open-in-browser. The app supplies an
`AnalyzerConfig` (all text + accepted file suffixes) and a worker
`(primary_path, sidecars: tuple[Path, ...], suggested_report_path) -> report_path`.

Optional companion files ("sidecars"): set `sidecar_suffixes` (e.g.
`(".csv",)`) on the config and the chassis classifies every drop by
suffix via `classify_paths`, keeps removable chips per sidecar, shows an
"Attach…" button, and passes the full sidecar tuple to the worker.
With `sidecar_suffixes` empty (default) behavior is plain single-file.
Name rules (app-specific file prefixes) belong to the app's worker, never the chassis.

`import logdeck` does not pull in tkinter. Install the GUI extra for
drag & drop: `pip install "logdeck[gui]"` (adds `tkinterdnd2`; apps
create a `TkinterDnD.Tk()` root — a plain `tk.Tk()` root degrades to
browse-only).

```python
import tkinter as tk
from logdeck.gui import AnalyzerConfig, AnalyzerWindow, run_centered

config = AnalyzerConfig(
    title="My Analyzer", heading="📊 My Analyzer", subtitle="Drop a file",
    accept_suffixes=(".log",), dialog_title="Pick a log",
    dialog_filetype_label="Logs", drop_hint="Drop .log here",
    browse_text="Browse...", process_text="▶ Analyze",
)
win = AnalyzerWindow(tk.Tk(), config, my_worker)
run_centered(win.root)
```

## Usage

```python
from logdeck import dicts_to_html_table, make_section, render_report

table = dicts_to_html_table(drives, columns=["id", "status"],
                            highlight_rules={"status": lambda s: s != "online"})
page = render_report(
    tabs=[{"id": "tab-errors", "title": "Errors", "content": make_section("Drives", table), "active": True}],
    now="2026-11-12 12:00:00",
    title="Log Report", heading="Log File Analysis", footer="Generated by Log Analyzer",
)
```

## Layout

    src/logdeck/report.py     deck assembly + bundled templates
    src/logdeck/tables.py     escaping / tables / sections
    src/logdeck/gui/          optional Tkinter analyzer-window chassis
    src/logdeck/templates/    report.html (page shell), report.js (tab & copy logic)
